SAÉ 1.05 : Automatisation d'un flux de données

Python Automatisation CSV Qualité

Contexte et Objectifs

Pour cette SAÉ, je devais automatiser le traitement de données provenant de plusieurs sources afin de produire des rapports exploitables. Le projet demandait de garantir la qualité des données et de faciliter leur exploitation pour un usage métier.

Compétences visées :

  • Analyser un besoin fonctionnel.
  • Écrire des scripts d'automatisation fiables.
  • Assurer la qualité des données importées.
  • Documenter la solution et son usage.
